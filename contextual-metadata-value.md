# Contextual Metadata Value

Contextual metadata—such as the date, source, and related projects—provides the "connective tissue" that makes a note meaningful over time. It answers the question "Why does this matter?" long after the original spark of the idea has faded. Metadata acts as a bridge between the moment of capture and the moment of retrieval.
