# Getting Things Done

Getting Things Done (GTD) is a productivity framework developed by David Allen. It is based on the idea that a person needs to move tasks and projects out of the mind by recording them externally and then breaking them into actionable work items. This allows one to focus on performing tasks instead of remembering them. The system is built around five stages: Capture, Clarify, Organize, Reflect, and Engage.
