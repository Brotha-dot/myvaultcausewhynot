# The ABCDE Method of Prioritization

Before you start work, list everything you have to do. Then, mark each item with A, B, C, D, or E. 'A' tasks are must-do (frogs), 'B' are should-do, 'C' are nice-to-do.

'D' tasks are for delegation, and 'E' are for elimination. The rule is never to do a 'B' task when an 'A' task is still unfinished. This simple system ensures you are always working on your highest-value activities.
