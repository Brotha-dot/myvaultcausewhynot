# The Rubber Duck effect requires active mental engagement

Explaining a problem to a "rubber duck" works because it forces you to verbalize and structure your thoughts. AI can act as a more interactive duck, but if it provides the answer too quickly, it cuts off the mental process that leads to self-correction and insight. The [[the-rubber-duck-effect-requires-active-mental-engagement|rubber duck effect]] is essential for building [[mental-models-must-be-built-manually-to-be-durable|durable mental models]].
