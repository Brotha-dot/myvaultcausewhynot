# AI-Assisted Development

This topic explores the intersection of artificial intelligence and software engineering, focusing on how to use AI tools effectively while maintaining code quality, mental models, and long-term maintainability.

## Key Principles
- [[Intentional coding is the foundation of maintainable software]]
- [[AI usage should augment, not replace, cognitive effort]]
- [[AI should be the last resort for logic, the first for syntax]]

## Risks and Challenges
- [[Over-reliance on AI leads to architectural blindness]]
- [[Skill atrophy is a silent cost of automated assistance]]
- [[AI-generated code often introduces subtle debugging debt]]

## Learning and Mastery
- [[The struggle of debugging is where true learning happens]]
- [[The 'Senior' intuition is built on years of manual failure]]
- [[Mental models must be built manually to be durable]]
