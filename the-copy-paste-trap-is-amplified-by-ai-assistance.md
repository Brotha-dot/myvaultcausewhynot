# The "Copy-Paste" trap is amplified by AI assistance

The traditional copy-paste problem (using code you don't understand) is supercharged by AI, which can generate large blocks of code instantly. This encourages a "cargo cult" programming style where code is added because it seems to work, without any grasp of its underlying mechanics. This often leads to [[ai-tools-can-act-as-a-bypass-for-critical-thinking|bypassing critical thinking]].
