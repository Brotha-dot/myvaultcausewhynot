# AI-generated code often introduces subtle debugging debt

Code generated by AI can appear correct but contain edge cases or logic flaws that are hard to spot. This "debugging debt" accumulates over time, as the developer becomes less familiar with the code they are supposedly maintaining, making future troubleshooting exponentially harder. This is a form of [[technical-debt-accumulates-when-ai-writes-the-how-without-the-why|technical debt]] that is often invisible until it's too late.
