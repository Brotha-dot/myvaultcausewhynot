# The CODE Framework

The CODE framework is the heart of Building a Second Brain. It stands for Capture, Organize, Distill, and Express. Capture is about saving things that resonate. Organize is about putting them in places where they will be actionable. Distill is about finding the core essence of the note. Express is about using the knowledge to create something new.
