# Skill atrophy is a silent cost of automated assistance

Just as GPS can weaken one's sense of direction, AI coding assistants can weaken a developer's ability to recall syntax, solve algorithmic problems, or structure code without help. This atrophy makes the developer dependent on the tool and less capable of working in environments where it is unavailable or restricted. This is a primary concern for [[junior-developers-are-most-at-risk-from-ai-over-reliance|junior developers]].
