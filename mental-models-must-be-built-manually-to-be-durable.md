# Mental models must be built manually to be durable

A developer's mental model of a codebase is built through the active process of reading, writing, and reasoning about code. AI-assisted development can create a "hollow" understanding where the developer knows *what* the code does but lacks the internal model of *how* and *why* it works that way. This is why [[the-struggle-of-debugging-is-where-true-learning-happens|manual debugging]] is such an important teacher.
