# How to Read a Book

How to Read a Book is the classic guide to intelligent reading. Mortimer J. Adler (along with Charles Van Doren in later editions) provides a comprehensive framework for active, critical reading. The book outlines four distinct levels of reading, from basic literacy to the highly sophisticated level of syntopical reading, where one synthesizes information from multiple sources on a single subject. It is an essential resource for anyone who wants to read for understanding rather than just information.
