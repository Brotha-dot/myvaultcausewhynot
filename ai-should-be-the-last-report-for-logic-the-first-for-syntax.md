# AI should be the last resort for logic, the first for syntax

To maintain cognitive sharpness, a developer should attempt to solve the logic of a problem first. AI should only be called upon once the logic is clear, to help with the "translation" of that logic into specific syntax or to handle repetitive patterns. This prevents [[skill-atrophy-is-a-silent-cost-of-automated-assistance|skill atrophy]] and keeps the developer in control.
