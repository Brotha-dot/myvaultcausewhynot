# Coding speed is often a distraction from coding quality

AI is marketed as a productivity booster that increases coding speed. However, in software engineering, speed is rarely the bottleneck; the real challenges are maintenance, clarity, and architectural soundness. Fast coding often leads to more "waste" if the code isn't well-conceived, potentially increasing [[technical-debt-accumulates-when-ai-writes-the-how-without-the-why|technical debt]].
